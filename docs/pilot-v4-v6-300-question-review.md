# 300题 v4 与 v6 精判逐题对照复核

复核日期：2026-09-15

## 1. 复核口径

- 粒度：300个题目打标单元逐题复核，不是抽样。
- `合理多标`不算错误：只要Label能由当前设问、选项正误判断、答案或解析合理支持，即可保留。
- 允许漏标、允许空标；空结果被过滤时不记为错标，但若v4已有可靠标签而v6丢失，则单列为“v6覆盖下降”。
- 只有错误Label在v6中被保留并进入训练候选，才记为“v6精度改差”。
- `E`表示`need_expand_recall`，`C`表示`context_insufficient`，`train`按非空且E/C均为0重新计算。
- 本表是基于题干、父题材料、选项、答案、解析及老师Label释义的人工语义审计；没有独立金标，因此“等价可接受”不等于证明标签集合唯一。

核心判断：v6总体方向是改好而不是改坏；真正需要阻塞全量的是少量`v6精度改差`和`两版均需处理`。覆盖下降只影响训练数据产量，不污染留下的数据。
