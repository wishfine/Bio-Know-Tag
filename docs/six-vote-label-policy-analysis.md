# 六票结果到逐 Label 打标策略：分析与教师抽审设计

状态：设计稿。六票一致性是模型行为证据，不是人工金标；任何“自动通过/自动排除”须经教师盲审校准后确定。分析对象是当前 458 个高中生物 Label、同一份冻结题目与候选、Qwen 三票和 DS 三票。已确认业务约束：**自动通过错标率上限 ≤5%；本轮教师预算约 1,000 个题目–Label 判断**。自动排除的可接受漏标率尚未给出，因此不能按同一阈值直接放行负例。

## 1. 统一的分析单元

最小单元为 `(question_id, label_id)`。对同一候选 Label 记录 `Q0–Q3`、`D0–D3`，得到 16 格 `Qx/Dy` 票型。所有比例必须同时写出分子、分母与分母定义：

- `六票共同成功题`：仅用于模型间可比分析；未完成或错误请求不当作反对票。
- `候选曝光题`：该 Label 实际进入六票相同候选集的题。只有在此范围内才能定义 `Q0/D0`。
- `至少一票选中的题`：衡量该 Label 被考虑后的稳定性。`Q3/D3 / 至少一票选中` 与 `Q3/D3 / 候选曝光` 是两种不同指标。
- `有旧 knw_id 的题`：旧标只作弱监督分层，不是正确答案；过期 ID 单列。

同一道多标签题可能同时有 `Q3/D3`、`Q3/D2`、`Q0/D3` 等状态。整题的“两个模型完整 Label 集合是否相同”与逐 Label 16 格分布要分别报告，不能将六票简单加成 `4/6`。

## 2. 分层维度与可解释指标

每个 Label 至少输出下表，默认同时展示绝对题数和条件率；长尾另给不确定区间，不按百分比直接排序。

| 维度 | 指标 | 能支持的判断 | 不能支持的判断 |
|---|---|---|---|
| 16 格票型 | 每格题数、候选曝光占比、至少一票选中条件占比 | 找稳定共识、单模型偏选、交叉冲突、边界波动 | 哪个模型正确 |
| 模型内稳定性 | Qwen/DS 各自全同、2+1、三票各不同；第 3 票对前两票的增益 | 是否值得对该 Label 全量投第 3 票 | 稳定即准确 |
| 模型间关系 | 双方多数集合相同、Qwen 多选、DS 多选、双向增减；`Q3/D0` 与 `Q0/D3` | 识别可聚类的系统性释义边界 | 简单六票多数 |
| 题型与内容 | standalone、小题、父题额外；父题/图片/解析文本缺失、内容复核标记 | 定位污染和不可靠输入 | 把小题结果直接外推父题 |
| 检索与历史 | 候选 rank、sparse/dense/legacy 来源、旧标签是否在 Top25 | 定位召回问题、旧标锚定与标签漂移 | 把旧 ID 当金标 |
| Label 先验证据 | 独立题正样本释义覆盖、相邻硬负样本复核、长尾样本量、历史人工审核 | 排定抽审优先级 | 把 DS 对 DS 的判断当独立金标 |

`Q3/D3` 专项只是 16 格中的一个过滤视图：既要看它覆盖多少题，也要看高频 Label 是否只是本来就高曝光，以及同题其他**至少一票选中**的 Label 在 `Q3/D2`、`Q2/D3`、`Q2/D2`、强冲突还是弱支持。大量 `Q0/D0` 候选不混入“同题其他被选 Label”分布。

## 3. 先用现有 14 万题完成的分析

固定六票共同成功交集，计算 `16 格 × Label × 题型` 数据立方体，并同时给出：

1. 全局体量、每 Label 体量和候选曝光，避免“大 Label 的绝对冲突数高”被误解为异常率高。
2. 按题型/图像缺失/父题背景拆分的同一票型条件率；抽样看是否是题目内容问题。
3. 每个 Label 的 `Q3/D3`、`Q3/D0`、`Q0/D3`、`Q2/D1`、`Q1/D2` 等集中程度，及稳定冲突最常见的相邻 Label 对。
4. 如果只留两票：第一、二票相同而第三票反对的比例；前两票分歧时第三票能否形成 2:1；分别按 Label 与题型报告。
5. 每个高频模式抽取题目原文、解析、候选卡和六票证据，先形成可复核的错误假设：释义偏宽/偏窄、Label 名称与定义冲突、旧标误挂、父题污染、缺图、检索遗漏或模型随机波动。

现有快照中 Qwen 三票集合全同 91.91%，DS 85.06%；两模型多数集合不同 51.31%，其中 34.78% 的题双方各自三票一致却互相不同。这说明“加同模型投票”主要解决模型内波动，不能替代对系统性跨模型冲突的边界审核。当前快照可能偏向输入前段，不能直接外推全量。

## 4. 教师只审样本：两阶段校准

### 第一阶段：发现问题，不决定放行

按 `票型 × Label 风险等级 × 题型/内容质量` 抽题，保留每个抽样层的总体数量、随机种子、抽样概率和题目去重/父题簇。既做随机样本以估计总体风险，也做高风险定向样本以发现错误模式；两者**不得混合成一个未加权错误率**。同题多个 Label 可在一次界面中审核，但统计置信区间要按题目/父题聚类，不能假设判断完全独立。

优先抽：`Q3/D0`、`Q0/D3` 稳定冲突；`Q2/D1`、`Q1/D2` 边界；高频 Label 的 `Q3/D3` 正例；候选曝光但 `Q0/D0` 的潜在漏标；父子题、缺图及长尾。对高频稳定冲突先按 Label 对和错误类型聚类，老师审代表题，不让老师逐题审数万条。

### 第二阶段：验证可复用规则

若某类题的分歧能由释义边界或题型规则解释，冻结规则，再取**未用于制定规则**的教师盲审样本验证。若使用模型 Judge，它必须是六票以外的已校准模型，先在教师样本上量化其错标拦截率、合理共标误杀率、漏标发现率；不能把参与投票的 DS 当作独立 Judge。

对拟自动通过的层，报告人工确认精确率及其单侧 95% 置信下界；对拟自动排除的层，报告漏标率上界。若某层抽 `n` 个且零错误，单侧 95% 错误率上界为 `1−0.05^(1/n)`：要支持“错误率低于 5%”，需约 **59 个零错误**的随机验证样本；2% 约需 149 个，1% 约需 299 个。若出现错误，所需样本更多。**这是每个可交换统计层的量级，不是说 458 个 Label 都各审 59 题。**共享一个层前，需验证 Label 间误差没有明显异质性；高风险 Label 和样本不足的长尾不能靠总体均值自动放行。

按 1,000 个判断先预留而不一次抽完：

| 阶段 | 暂留名额 | 目的与抽样约束 |
|---|---:|---|
| 探索性盲审 | 300 | Q3/D3、稳定跨模型冲突、近一致/模型内波动、候选曝光 Q0/D0 分层抽取；每层保留随机抽样概率。用于发现问题，不用于同批验证所发现的规则。 |
| 高影响簇诊断 | 400 | 按高频 Label 对、长尾、父子题、缺图/文本问题定向过采样；识别能否修释义或形成可复用边界规则。此批不能直接当总体错误率。 |
| 独立留出验证 | 300 | 只验证前两阶段冻结的自动通过候选层和规则；可按约 5 个各 60 题的同质层分配，或合并为更少、更稳的层。若一层不足 59 个零错误样本，不能仅凭“未见错误”宣称达到 5%。 |

以上是初始预算框架，首 300 题的错误分布出来后可调整尚未抽出的名额，但不得把已用于发明规则的题冒充独立验证。教师一次看一道题的多个 Label 可以降低界面操作量，统计预算仍按实际的题目–Label 判断计数。

分层总体错标率按真实层体量加权：`Σ (N_h / N) × 错误样本_h / 审核样本_h`；定向过采样需按抽样概率校正。除点估计还要报告区间、覆盖的题量、预计需要教师处理的题量，以及如果拒判会损失多少可训练样本。不能只报告“模型一致率”。

## 5. 逐 Label 决策卡与路由

每张卡片都包含：候选曝光数、16 格计数/条件率、题型与图片分层、历史释义证据、代表题、教师金标样本数与错误数/区间、可自动处理覆盖量、仍需审核量。由此路由：

| 暂定路由 | 条件 | 处理 |
|---|---|---|
| 自动通过候选 | 例如 `Q3/D3` 且内容可靠、Label 边界清楚，并且教师校准达到业务错误率上限 | 可进入自动层；持续随机质检，不能仅凭票型放行 |
| 自动排除候选 | 候选已曝光的 `Q0/D0`，且抽审证实漏标风险可接受 | 只对该候选 Label 排除；候选外漏召另查 |
| 规则/释义修复 | 稳定跨模型冲突集中在少数 Label 对或场景 | 先修边界，再在独立教师样本验证并回放全量 |
| 独立 Judge | 投票不一致且模型 Judge 的教师校准足够好 | Judge 无法定夺或与高置信证据冲突时送教师 |
| 教师必审/暂缓 | 关键长尾、释义名实冲突、缺图信息不足、候选外需补标、规则外高风险 | 优先处理高影响簇；未审的保持未决，不伪造金标 |

自动通过错标率已定为 ≤5%、教师预算约 1,000；**自动排除的漏标率上限仍待业务确认**。参数未定或置信区间未达标时，输出 `待校准/待审核`，不把“一致”自动翻译为“正确”。

## 6. 实现边界

保留当前只读 `Q3/D3` 视图，通用票型层现已提供 `scripts/analyze_vote_pattern_cube.py`：读入六份追加式证据，按成功题号对齐并强制核验三份输入 SHA 和每票实际候选映射；生成逐题–Label 的 `Qx/Dy`；用候选 sidecar 补足 `Q0/D0` 的曝光分母；回连打标单元和数据质量标记；按 Label、题型、质量标记、候选 rank、候选来源、旧标分层并保留每 Label 关键票型的代表题。当前内存版分析上限为每票 50 万成功题；达到全量规模时改用 SQLite/分块外排中间层，不能简单调高上限冒 OOM 风险。代表题只用于诊断，不是概率抽审样本；教师抽审仍需另外记录抽样概率和盲审结论。

教师审核结果作为独立表按 `(question_id, label_id, reviewer, taxonomy_version)` 接入；票型、释义、候选、教师结论分别保留来源与版本。这样后续换模型、改 prompt 或修释义都能重算策略，而不覆盖原始判断。
